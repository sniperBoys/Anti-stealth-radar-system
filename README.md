# Networked Radar System for Stealth Detection

**Inventor:** Muhammad Hamza

## Idea
5 radars border par lagayi jayengi jo interconnected hongi. Jab stealth jet signal absorb karti hai, toh signal loss detect hota hai aur alert generate hota hai.

## Technology
- Signal Loss Detection
- TDOA (Time Difference of Arrival)
- Triangulation
